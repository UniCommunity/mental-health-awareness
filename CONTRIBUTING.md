# Contributing

Thank you for helping keep this resource accurate and safe.

## Rules that will not be bent

- No instructions, details, or research notes on methods of suicide, self-harm, or violence.
- No graphic descriptions of deaths.
- No medical advice presented as personalized treatment.
- Crisis resources stay at the top of the README.
- Prefer primary sources: WHO, IASP, CDC, SAMHSA, NIMH, peer-reviewed reviews, named program evaluations.

## How to add content

1. Fork / branch.
2. Edit or add Markdown under `docs/`.
3. Cite the source in the file (organization + year + URL).
4. Use calm, non-stigmatizing language.
5. Open a pull request describing why the change is needed.

## Style

- Second person is fine ("you can call").
- Short paragraphs.
- No all-caps urgency except in crisis headers.
- Inclusive of LGBTQ+, disabled, racialized, and rural youth without tokenizing.

## Reporting errors

Open an issue titled `correction:` with the page, the sentence, and a better source.

If you are in crisis, do not use GitHub issues as a helpline. Use [docs/crisis-resources.md](docs/crisis-resources.md).
