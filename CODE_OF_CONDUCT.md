# Code of conduct

This project is an educational space about mental health. Contributors and users should treat each other with dignity.

## Expected

- Respect privacy and lived experience.
- Challenge ideas without attacking people.
- Assume good intent, then correct harmful content quickly.
- Keep crisis conversations off issue trackers; point to helplines.

## Not allowed

- Harassment, hate, or targeting of people by identity.
- Sharing another person's private health information.
- Content that describes how to cause harm.
- Using this repo to solicit unsafe contact with minors.

## Enforcement

Maintainers may edit or remove content and block contributors who break these rules. If you see a safety problem in the repo itself, open a private report if possible or an issue labeled `safety`.
